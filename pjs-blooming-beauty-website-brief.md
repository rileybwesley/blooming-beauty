# PJ's Blooming Beauty Landscapes — Single-Page Website Creative & Build Brief

## Project Goal

Create a polished, professional, forward-facing single-page website for **PJ's Blooming Beauty Landscapes**.

The website should feel like a real local landscaping company with a premium presentation: welcoming, dependable, visually rich, easy to scan, and designed to convert visitors into consultation requests.

This should **not** feel like a generic AI-generated template. Avoid overly symmetrical layouts, generic gradients, excessive glassmorphism, fake dashboards, or trendy SaaS design patterns. The site should feel handcrafted for a landscaping and flower-bed renovation business.

The finished site must be delivered as a **single `index.html` file** with:

- HTML
- Tailwind CSS via CDN initialization
- Custom CSS inside the file
- Vanilla JavaScript inside the file
- No framework build step
- No external JS dependencies unless absolutely necessary
- Placeholder imagery from `https://picsum.photos/`
- Fully responsive layout
- Smooth, tasteful animation throughout

# Tailwind CDN Setup

Use the Tailwind CDN script in the document head.

Example:

```html
<script src="https://cdn.tailwindcss.com"></script>
```

Use a `tailwind.config` block for custom colors and fonts if desired.

Example direction:

```html
<script>
tailwind.config = {
  theme: {
    extend: {
      colors: {
        evergreen: '#173C2A',
        forest: '#24593B',
        leaf: '#4B7D50',
        cream: '#F8F4EA',
        burgundy: '#8F1D2C',
        sage: '#A8B9A3'
      }
    }
  }
}
</script>
```

Custom CSS should still be used for:

- animation keyframes
- before/after slider
- decorative effects
- special image masks
- gradients
- advanced hover effects
